# Kafka MCP

Inspects and produces to Apache Kafka. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mcp-kafka

Installs from the Camillia hub as `kafka-mcp-1cc71c`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
